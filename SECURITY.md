# Security

If you find a security problem in Lettra, please don't open a public issue. Report it privately from the
repository's **Security** tab (Report a vulnerability), and I'll get back to you as soon as I can.

Only the latest release gets fixes. Lettra updates itself, so a fix reaches everyone through the normal
update.

Things worth reporting include anything that lets a web page, a font file or a download run code or read
files outside what Lettra needs, and anything that could get the updater to install something other than
an official release.
